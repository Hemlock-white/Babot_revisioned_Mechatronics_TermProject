# BaBot 明日救援：照表做，不跳關

**目標：**用最少時間找出 A／B 不動的原因，換上可靠的「位置型」舵機，最後才試平衡。請一人操作電源與萬用表、一人輸入指令、一人看舵機／機構。每次換線、舵機或舵片，USB 與 J1 **都先斷電**。卡住、異常嗡鳴或發熱時立刻關 J1。

**今天請先備齊：**萬用表、原配舵片／短螺絲、你們已有的**位置型 TowerPro MG90S**（至少兩顆）、有資料功能的 Micro USB 線，以及下表任一可靠 5 V 電源。先保留 C，不必拆它的舵片。**連續旋轉型 MG90S 不可拿來替代**；同一脈寬對它是轉速，不是位置。MG995 體積與安裝孔位不同、負載電流也可能更大，明天只作桌上對照或機構確實可裝時的備案，不列為優先替代。[TowerPro MG90S](https://towerpro.com.tw/product/mg90s-3/)、[MG995／MG996R 外形與規格](https://towerpro.com.tw/product/mg995-robot-servo-180-rotation/)。

## 0. J1 電源怎麼取得

| 手邊選項 | 明天可否用 | 接法／條件 |
| --- | --- | --- |
| 實驗室直流電源 | **首選** | 設 **5.0 V**，電流限制先設約 **3 A**；正極 J1-1、負極 J1-2。若動作時進入限流，先檢查卡機與電流表，再決定是否調整。3 A 是測試起點，非保證值。 |
| 標示 5 V、至少 3 A 的穩壓變壓器／行動電源 | **可用來試** | 先確認實際輸出 5 V、線材能承受電流、極性正確；帶三支動作時在 H 接頭量電壓。若掉壓或保護斷電，就換來源。 |
| **兩顆 18650 串聯＋合適的降壓模組** | **有模組且懂接法才用** | 兩顆滿電可達 **8.4 V**，必須經輸入範圍涵蓋電池電壓、可連續輸出約 5 V／數安培的 **DC-DC buck**，先不接 PCB 把輸出調到 5.0 V。用匹配且有保護的電池／電池盒；先量極性，負極接 J1-2。模組標稱「3 A」仍要實測帶負載是否掉壓／過熱。 |
| 一顆 18650 或兩顆並聯、兩顆串聯直接接 J1、繼電器 | **不能當 5 V 穩壓方案** | 單顆／並聯約 3–4.2 V，不夠；兩顆串聯最高 8.4 V，太高；繼電器只能開關，**不會降壓或增加供電能力**。 |
| 原四顆 R6/UM3 | **只有通過下方帶負載量測才暫用** | 空載 6 V 或曾量到 5.6 V 不算通過。R6 通常是碳鋅 AA；[Panasonic R6 規格](https://industry.panasonic.eu/pd-33092/batteries/primary-batteries/zinc-carbon-and-alkaline-batteries/zinc-carbon-batteries/r6)。 |

Plate 的 **21 顆 IR 發射管是用電流，不是「0.2–0.3 V」**：21 組 330 Ω 支路在亮燈期間合計約 **0.2–0.3 A**（估算，實際依供電和 LED 壓降）。舵機卡住時電流可大幅上升；三支並非平均分配「剩下的電流」。C 能轉、A/B 不轉，仍可能是 A/B 本身摩擦／故障加上電源壓降一起造成。Arduino 也建議多顆舵機用外部電源並共地。[Arduino 說明](https://support.arduino.cc/hc/en-us/articles/360017053760-Troubleshoot-servo-motors)。

**禁止：**用 Uno 的 5 V 腳供三支舵機；萬用表電流檔跨接 J1 正負；帶電換排線。設計上 Micro 的 USB 供邏輯，J1 供舵機與 Plate IR；只插 USB 時 J1 曾讀到約 5 V，不能因此當作舵機電源。

## 1. 先隔離 A／B：只測裸軸（約 15 分鐘）

1. 先拔下連桿、舵片與舵片螺絲；三支中**一次只插一顆**到 H1。H1-1＝訊號、H1-2＝舵機正電、H1-3＝GND。USB 與 J1 斷電後才換舵機。
2. Arduino IDE 開 [救援程式](../software/rescue_balance/rescue_balance.ino)，選 **Arduino Micro** 上傳；序列監控設 **115200、Newline**。輸入 `help` 有指令、`status` 顯示 `OFF` 才接第 0 節已確認的 J1 電源。
3. 對同一顆輸入：`arm` → `pulse a 1400` → `pulse a 1600` → `pulse a 1500` → `off`。看**輸出軸本身**是否每次到不同位置且停住。依序用同一個 H1 測 C（對照）、A、B、備用的位置型 TowerPro MG90S。這裡指令的 `a` 永遠是 H1，與實體舵機名稱無關。

| 看到的結果 | 立即處置 |
| --- | --- |
| C、備用 TowerPro 正常；A 或 B **裸軸**不動、跳動、嗡鳴或打齒 | 先換上備用**位置型** TowerPro。不要花時間調 PID 或重焊 PCB。若備用也失敗，進第 2 節查電源。 |
| A/B 裸軸正常，裝原舵片才卡 | 舵片與軸齒必須吻合，且不能磨外殼。用該顆的原配舵片與適合長度螺絲重裝；螺絲鎖到舵片不滑動即可，不能靠「留鬆」作長期解法。B 原本裝錯舵片，優先換正確舵片。 |
| A/B 裸軸正常，正確舵片也正常 | 單顆通過；進第 2 節測同時接三顆。 |
| C 在 H1 正常，A/B 在 H1 不正常 | 同一接頭與程式已由 C 證實可用，A/B 或其負載是較強嫌疑；電源是否同時參與仍用第 2 節定案。 |

## 2. 三顆同接時測電壓（約 10 分鐘）

1. 只裝正確舵片，**不裝連桿**；斷電把三支位置型舵機接 H1/H2/H3。用 `arm` 到中心，再在 `LEVEL` 輸入 `pulse a 1400`、`pulse b 1600`、`pulse c 1400`，接著各自改回 1500。若卡住，先關 J1。
2. 萬用表設**直流電壓**。黑筆放 J1-2，紅筆 J1-1；再黑筆放 H1-3、紅筆 H1-2（H2/H3 同理）。**在 A/B 停住或三支移動當下**量，不用空載讀值判斷。記錄 J1、H1、H2、H3 的最低讀值；有 MIN/MAX 功能就啟用。不要用表筆短接相鄰針腳。

| 實測 | 結論／下一步 |
| --- | --- |
| 故障當下 H1/H2/H3 **低於 4.8 V**、電源限流／掉電，或 Arduino 重啟 | 先換穩壓電源、電池盒／線材；若某支一接就造成掉壓，也把那支當卡住的故障舵機更換。 |
| J1 約 5.0–5.6 V，但某個 H 接頭低很多 | 查該排針、線與 PCB 供電接點。 |
| J1、各 H 在故障當下都維持約 **4.8–6.0 V**，C／備用品正常但 A/B 不動 | 優先判為 A/B 舵機／舵片問題，換位置型 TowerPro；不要再把電池當唯一原因。普通萬用表可能漏掉短暫掉壓，換穩壓源後再試一次是最直接交叉驗證。 |
| 原 R6 失敗，換穩壓源後三支都動 | 供電是主要問題；仍確認 A/B 不再卡住，才進第 3 節。 |

**通關：**三支同接可重複完成 1400／1500／1600 µs 小幅動作，沒有卡住或長時間嗡鳴，帶負載電壓合格。若沒有三支可靠的位置型舵機，無法用三點機構平衡球。

## 3. 確認感測（約 5 分鐘）

USB 與 J1 斷電接好 Base–Plate 20 芯排線，**pin 1 對 pin 1**；再插 USB、J1，救援程式保持 `OFF`。空盤看約 10 行：預期 `NO BALL`、`spread < 220`。球放不同位置：預期 `BALL`、`spread ≥ 220`、`center=(x,y)` 改變。你們先前空盤多約 20–160、有球常 300–900，因此這關通常很快。若空盤誤報，試 `threshold 300 220`；若空盤和有球範圍重疊，先查光照、球與排線。若全無讀值，改燒 [Plate 測試程式](../software/test_code_plate/test_code_plate.ino) 跑 `scan`，修好後再燒回救援程式。

## 4. 裝機構、試方向（剩餘時間）

1. `arm` 後三支在 **1500 µs**。這和舊測試版 `main` 空盤約 **1245 µs** 不同；**先斷電並重新定位舵片**，讓平台與連桿可在這個中心角度自然接合。逐支可用 `center a 1510` 這類指令微調，允許 1400–1600 µs；把 A/B/C 三個中心值寫下。斷電重開後會回預設 1500；若已裝連桿，重開機先在 `OFF` 輸入三個 `center`，然後才 `arm`。
2. 裝好連桿後用墊塊托住平台、手離開連桿，輸入 `arm`。預期 `LEVEL` 時平台接近水平，三支不撞、不嗡鳴，J1/H 電壓仍合格。若不是，關 J1，先改舵片位置／連桿長度。
3. 球先固定在左側，輸入 `run`；預期平台**左側升高**，球會朝中心滾。右、前、後各試 1–2 秒。只反左右就 `level` → `flipx` → `run`；只反前後用 `flipy`。若左右球位卻造成前後傾斜，查機構 A/B/C 順序與 Plate 朝向，不能靠 flip 修。
4. 四方位都正確，才短暫放球自由滾動。救援程式初始 `gain 2 4`、`limit 80`，動態最大只偏中心 ±80 µs、絕對脈寬 1300–1700 µs。反應太弱且無碰撞，可在 `level` 下改 `limit 120`、`gain 3 4`；若來回振盪，試 `gain 1.5 2`。每次只改一組，記錄結果。輸入 `off` 前先托住平台，停脈波後可能下垂。

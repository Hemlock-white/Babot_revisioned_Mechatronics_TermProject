# BaBot Base＋Plate＋舵機救援操作單

照 **步驟 0 → 7** 做。每一步先看「預期」，不符就照下面的小表格處理；該步未通過，不進下一步。由一人讀指令、一人操作與看舵機、一人拿表筆。**任何換線、拆舵片、裝連桿都先拔 USB、關 J1。**

## 目前已知、要排除什麼、查到後怎麼修

| 目前已知 | 可能狀況 | 本次要確認 | 確認後的修法 |
| --- | --- | --- | --- |
| Base／Plate 曾測通；Q4 換後 16 路有讀值，球位會變。 | 組裝後排線鬆脫、電源不穩。 | 空盤／有球仍可分辨。 | 修排線或電源，再跑 Plate `scan`。 |
| C 在不同 H 接頭都能轉。 | A／B 舵機或舵片比接頭更可疑。 | C、A、B 在**同一 H1** 上的裸軸表現。 | A／B 裸軸失敗就換現有的**位置型 TowerPro MG90S**。 |
| A 鬆舵片螺絲才較順；B 曾裝錯舵片，換舵片後仍卡。 | 舵片齒孔不合、螺絲太長／太緊、外殼摩擦、內齒輪損傷。 | 裸軸與「正確舵片＋螺絲」結果是否不同。 | 裸軸好就修舵片／螺絲；裸軸也壞就換舵機。 |
| 四顆 R6/UM3 串聯曾量到 5.6 V；舊 `main` 開機時三支曾動。 | 三顆同動或卡住時掉壓；舊測試與現在脈寬不同。 | **故障當下** J1 和 H1–H3 電壓。 | 低於 4.8 V 就換穩壓電源／線材；電壓合格仍失敗就換舵機。 |

**馬達選擇：**優先保留正常的 C，拿現有**位置型** TowerPro MG90S 換 A／B。連續旋轉型 MG90S 不能執行角度控制。MG995 體積和安裝孔位不同，暫不拿來趕時間改機構。[TowerPro MG90S](https://towerpro.com.tw/product/mg90s-3/)、[MG995 外形](https://towerpro.com.tw/product/mg995-robot-servo-180-rotation/)。

## 步驟 0｜準備電源與接線

**操作**

1. 準備 Arduino Micro USB 資料線、萬用表、正確的舵片／螺絲、三顆位置型 MG90S、能托住平台的墊塊。
2. J1 使用 **5.0 V 穩壓電源**：實驗室電源或標示至少 5 V／3 A 的可靠電源。正極 **J1-1**，負極 **J1-2**。先在**未接 PCB**時用直流電壓檔量輸出和極性；應約 5.0 V。3 A 只是測試電源的起點，是否足夠仍看步驟 5 的帶負載電壓。
3. 若只有 18650：**兩顆串聯 → 合適的 5 V 降壓模組 → J1**，先調好輸出再接板。模組須能承受電池最高 8.4 V 輸入，連續輸出數安培；使用配對且有保護的電池／電池盒。**沒有降壓模組就別直接接兩顆 18650**。繼電器不能穩壓。一顆 18650 也不足 5 V。
4. 四顆 R6/UM3 可拿來做對照，但「曾量到 5.6 V」不代表三支動作時也有 5.6 V。Plate 21 顆 IR 用的是估計約 **0.2–0.3 A 電流**（亮燈期間），不是 0.2–0.3 V；電源還要供三支舵機。R6 常為碳鋅 AA。[Panasonic R6](https://industry.panasonic.eu/pd-33092/batteries/primary-batteries/zinc-carbon-and-alkaline-batteries/zinc-carbon-batteries/r6)。

| 看到的結果 | 接下來 |
| --- | --- |
| 輸出約 5.0 V、極性正確 | 進步驟 1。 |
| 電壓大於 6.0 V、極性不確定、降壓模組無法穩定在 5 V | **不接 J1**；先換／調整電源。 |
| 只有繼電器、沒有 5 V 電源或降壓模組 | 繼電器幫不上忙；找實驗室電源／5 V 變壓器。 |

## 步驟 1｜燒錄並確認安全起始狀態

**操作**

1. **先拔下三支舵機、J1 斷電。**USB 接 Base Arduino Micro。
2. Arduino IDE 打開 [rescue_balance.ino](../software/rescue_balance/rescue_balance.ino)，板型選 **Arduino Micro**、選對埠後上傳。
3. Serial Monitor 設 **115200 baud、Newline**；輸入 `help`、`status`。

**預期：**有指令清單；狀態以 `OFF` 開頭。此時未送舵機脈波；程式可能仍持續掃 Plate。

| 看到的結果 | 接下來 |
| --- | --- |
| `OFF`、`help` 正常 | 進步驟 2。 |
| 無序列輸出／上傳失敗 | 查 USB 資料線、板型、埠；仍失敗先用已測過的 [test_code_base.ino](../software/test_code_base/test_code_base.ino) 測舵機，記下編譯／上傳錯誤。 |
| `status` 不是 `OFF` | 確認燒錄的是 `rescue_balance.ino`；在確認前不要裝連桿。 |

## 步驟 2｜用 C 作對照，測 A／B「裸軸」

**操作**

1. USB、J1 斷電。先只把 **C** 插 H1，保留它目前正常的舵片，不拆舵片或螺絲；但先卸下連桿。H1-1＝訊號、H1-2＝舵機電源、H1-3＝GND。上電後輸入 `arm` → `pulse a 1400` → `pulse a 1600` → `pulse a 1500` → `off`，確認 C 仍正常。
2. 雙電源斷電，取下 A、B 各自的連桿、舵片與舵片螺絲；依序把 A、B 插到**同一個 H1**，每顆重做同一串命令。只看**輸出軸本身**：每個命令停 1–2 秒，應轉到不同位置並停住。此處 `a` 指 H1，與實體舵機名稱無關。
3. 備用**位置型 TowerPro MG90S** 也用同一個 H1 測一次。C 測完放回，不需拆它正常的舵片。

| 看到的結果 | 判定 → 修法 |
| --- | --- |
| C 和備用 TowerPro 正常，A／B 裸軸不動、抖、停住、打齒 | A／B 本體較可疑 → 直接換正常的位置型 TowerPro。 |
| C 的舵片正常；A、B 裸軸都能重複到三個位置 | 舵機本體暫時通過 → 進步驟 3。 |
| 同一 H1 上連 C 都不動 | 本次接線／供電／燒錄不對 → 先查 J1、H1 插法及步驟 1。 |
| 只有兩顆同時接才不動 | 單顆不能定案 → 進步驟 4／5 帶負載量電壓。 |

## 步驟 3｜正確舵片與螺絲；專查 A、B

**操作**

1. 雙電源斷電。給每顆裝**與自身軸齒吻合**的舵片和原配螺絲；不要用另一顆「看起來能套」的舵片。先不裝連桿。
2. A、B 各自用 H1 重做步驟 2 的命令。看舵片是否和輸出軸**一起**到位，是否擦到外殼；斷電後檢查螺絲長度。不要把螺絲留鬆當修法。

| 看到的結果 | 判定 → 修法 |
| --- | --- |
| 裸軸正常、裝舵片才卡；鬆螺絲又改善 | 舵片／螺絲／外殼干涉 → 換原配舵片與適合長度螺絲，重新定位。 |
| 輸出軸轉、舵片不跟著轉 | 舵片齒孔打滑 → 換正確舵片，不靠加大脈寬。 |
| 裸軸和正確舵片都會卡 | 舵機內部較可疑 → 換備用位置型 TowerPro。 |
| 正確舵片下 A、B 都能反覆動作 | 進步驟 4。 |

## 步驟 4｜三顆同接，不裝連桿

**操作：**雙電源斷電；把通過前兩步的三顆位置型舵機接 H1/H2/H3，只有正確舵片；同時接上 Base–Plate 20 芯排線，確認 **pin 1 對 pin 1**，讓這次電源測試也包含 IR 負載。上電輸入 `arm`，預期三顆到 1500 µs，狀態 `LEVEL`。再輸入 `pulse a 1400`、`pulse b 1600`、`pulse c 1400`；然後 `pulse a 1500`、`pulse b 1500`、`pulse c 1500`。重複一次。

| 看到的結果 | 判定 → 修法 |
| --- | --- |
| 三顆都能重複動，無異常嗡鳴 | 進步驟 5 量電壓，再裝機構。 |
| C 正常、A／B 失效 | **保持故障狀態，立刻做步驟 5 帶負載量測**；不要先猜是程式。 |
| 某一顆一接上就持續嗡鳴、外殼熱、電源限流 | 關 J1；先換該顆舵機，再做步驟 5。 |

## 步驟 5｜在故障發生時量電壓

**操作：**萬用表設**直流電壓檔**。讓另一位組員操作步驟 4 的命令；黑筆接 J1-2、紅筆 J1-1，記下 A／B 不動當下的讀值。再分別量 H1-2 對 H1-3、H2-2 對 H2-3、H3-2 對 H3-3。盡量用 MIN/MAX 功能；普通表可能漏掉短暫掉壓。表筆不要碰到相鄰針腳。

| 故障當下讀值 | 判定 → 修法 |
| --- | --- |
| J1 或 H 接頭低於 **4.8 V**，電源限流，或 Arduino 重啟 | 電源／線材／卡機負載有問題 → 換 5 V 穩壓源；若只有接某顆才掉壓，也換該顆。再重做步驟 4。 |
| J1 約 5 V、某個 H 明顯低很多 | H 排針、焊點或線有問題 → 修該支供電路徑。 |
| J1、三個 H 約 **4.8–6.0 V**，但 A/B 不動；備用位置型 TowerPro 在同一接頭會動 | A/B 本體／舵片問題較強 → 換備用 TowerPro。 |
| 換穩壓源後三顆都動 | 原電池供電是主因 → 以新電源進步驟 6。 |

**通關：**三顆同接能動，且故障不再出現；帶負載電壓合格。5.6 V 只有在這個條件下量到，才支持「電壓夠」的判斷。[MG90S 資料表](../hardware/Electronincs_Datasheet/MG90S.PDF)列 4.8–6.0 V。

## 步驟 6｜確認整合感測

**操作：**步驟 4 已接好 Plate；若中途拔過排線，先雙電源斷電再確認 20 芯排線 pin 1 對 pin 1。輸入 `off`，確認救援程式顯示 `OFF`；空盤看約 10 行，再把球放左、中、右各看約 10 行。

**預期：**空盤 `NO BALL`、`spread < 220`；有球多數 `BALL`、`spread ≥ 220`，`center=(x,y)` 隨球位改變。你們之前空盤約 20–160、有球常 300–900；這是**本機實測參考**，不是每個環境的保證值。

| 看到的結果 | 判定 → 修法 |
| --- | --- |
| 空盤穩定 `NO BALL`、有球 `BALL` 且座標會變 | 進步驟 7。 |
| 空盤常誤報，球讀值與空盤分得開 | 試 `threshold 300 220`；確認空盤仍 `NO BALL`、有球仍 `BALL`。 |
| 全部 `NO BALL` 或讀值近零 | 查 J1、排線；改燒 [test_code_plate.ino](../software/test_code_plate/test_code_plate.ino)，`TEST_WITH_BASE=1`，輸入 `scan`。修好後**重新燒回**救援程式。 |
| 空盤和有球 spread 重疊 | 先固定光照、球與 Plate；不要只靠亂改閾值進行平衡測試。 |

## 步驟 7｜裝機構、檢查控制方向、短試平衡

**操作**

1. 不裝連桿時先 `arm`，三顆應在 **1500 µs**。救援程式的中心與舊測試版 `main` 空盤約 1245 µs 不同。雙電源斷電後**重新定位舵片**，讓連桿自然接上、平台接近水平；別用手硬扭軸。用墊塊托平台，手離開連桿，再上電 `arm`。若需微調中心，在 `LEVEL` 輸入如 `center a 1510`，範圍 1400–1600；記下 A/B/C 值。若重開機，先在 `OFF` 重輸入三個 `center`，才 `arm`。
2. **不放球**時預期 `LEVEL`：平台近水平、三支不撞機構、不持續嗡鳴。若不符，關 J1，修舵片位置或連桿。
3. 球用手固定在左邊，輸入 `run` 1–2 秒；平台左邊應升高，讓球有往中心滾的趨勢。右、前、後各重做。輸入 `level` 可回中心。只左右反向：`level` → `flipx` → `run`；只前後反向用 `flipy`。
4. 四方向都正確才短暫放球。預設 `gain 2 4`、`limit 80`；反應太小且沒碰撞時試 `level` → `limit 120` → `gain 3 4` → `run`；快速振盪時試 `gain 1.5 2`。每次只改一組並錄影。要輸入 `off` 前先托住平台；停脈波後可能下垂。

| 看到的結果 | 判定 → 修法 |
| --- | --- |
| `LEVEL` 就卡住或嗡鳴 | 機構中心／連桿干涉 → 關 J1，重定位舵片；不要加大 `limit`。 |
| 球在左邊，平台卻左邊下降；前後也類似 | 對應軸方向反了 → 用 `flipx`／`flipy` 後重試。 |
| 球左右移，平台卻前後傾斜 | 軸對應錯 → 查 A/B/C 連桿順序與 Plate 朝向；flip 不能交換軸。 |
| 四方向正確，但球很快滾出 | 保存影片與中心、電壓、spread；一次只微調一組 gain／limit。若機構碰撞或舵機卡住，立刻停。 |
| 球能反覆回中心並維持數秒 | 錄連續影片作正式成果，記錄電源與參數。 |

# BaBot development log

This log records the development sequence supported by the available files and conversation. Exact dates for the early conversion steps were not recorded. The new Git commits reconstruct milestones from KiCad's saved snapshots and the present files; their timestamps are **repository import dates**, not original design dates.

## Original project and local source archive

- **2025 source downloads:** Johan Link's [BABOT repository](https://github.com/JohanLink/BABOT) supplied `main.ino`, its README, and its CC BY-NC 4.0 license. Original Base and Plate PCBWay Gerbers/BOMs, the combined mechanical STL, a schematic PDF, and saved reference pages were downloaded separately. They are preserved in [`original/`](../original/) without editing their content. The PCBWay download names indicate 2025-05-26 for the Plate and 2025-05-27 for the Base; these are file labels, not verified manufacturing dates.
- **Early THT reconstruction; date not recorded:** Editable KiCad Base and Plate layouts were reconstructed from the original manufacturing Gerbers, flying-probe data, BOMs, and schematic information. The first Base version used an Arduino Micro module, through-hole parts, and the older digital-pot arrangement. The earliest surviving KiCad local-history snapshot is represented by the repository's initial THT commit; the superseded Base files remain in [`history/PCB/initial_THT_Base/`](../history/PCB/initial_THT_Base/).
- **Module and component revision; date not recorded:** The Base multiplexer IC was changed to a CD74HC4067 breakout module. A saved intermediate Base revision is captured as its own Git commit. The digital-pot module was then replaced by a Bourns 3296W 100 kΩ, 25-turn trimmer. The Plate design uses through-hole IR parts, a 2×10 header, and an FQP30N06L switch with a 220 Ω gate resistor. These circuit choices still need physical validation.
- **Routing attempts; date not recorded:** A two-layer Base layout was attempted, but its last recorded DRC had six signal and one GND connection open. The draft and trial files are archived in [`history/PCB/`](../history/PCB/). A separate four-layer Base was completed and routed; its last KiCad DRC reported zero violations and zero unconnected items.
- **2026-10-10 — Base fabrication and purchase data:** Four-layer Base Gerbers and drill files were exported and packaged as [`PCB/fabrication/BaBot_Base_THT_4layer_Gerbers.zip`](../PCB/fabrication/BaBot_Base_THT_4layer_Gerbers.zip). Both BOMs were grouped by purchasable part and given one-board/five-board quantities, stock fields, checkboxes, and supplier links. The Base power path uses a provisional 2 A assumption and an ordering recommendation of 1 oz inner copper; the actual servo loading has not been measured.
- **2026-10-11 — Repository organization:** Original downloads were separated from working files, early KiCad milestones were committed in sequence, and superseded Base work was moved to `history/`. `software/main.ino` is currently unchanged from the available upstream copy; there is no separately modified firmware yet. Hardware and system behavior have not been bench-tested.

## Routed Plate import and fabrication review

- **2026-10-13 — Gerbers supplied:** The owner supplied a newer two-layer `BaBot_Plate_v2THT` package, now retained under [`history/PCB/plate_invalid_gerbers/`](../history/PCB/plate_invalid_gerbers/). This is distinct from the original SMD Plate archive.
- **2026-10-13 — Export issue identified:** JLCPCB reported missing top and bottom solder masks. Both named mask files have no pad-opening graphics, and the package has no drill files. The Gerber job lists two copper layers, 1.6 mm thickness, and a 100.0456 × 101.5921 mm board. See the [original review](../history/PCB/plate_invalid_gerbers/plate/REVIEW_NOTES.md). That ZIP is **not fabrication-ready**.
- **2026-10-14 — Routed Plate source supplied and repaired:** The owner provided the editable routed project in `new.plate`. Its 143 through-hole pads had copper layers but no solder-mask layers, confirming the cause of the empty mask plots. A separate copy was repaired, then the corrected PCB, relevant Plate footprint definitions, and a new [Gerber/drill package](../PCB/fabrication/plate_tht/) were brought into this repository. KiCad 10 PCB DRC after zone refill found 0 violations and 0 unconnected items; the Base–Plate 20-pin nets match by pin number. The older unrouted board remains in [`history/PCB/plate_unrouted_draft/`](../history/PCB/plate_unrouted_draft/). Physical cable orientation, mechanical fit, and prototype optical/electrical tests remain pending.
- **2026-10-13 — Circuit teaching:** Separate original and current THT circuit guides were written, then turned into offline HTML lessons with electrical schematics, power maps, a two-scan timing graph, and interactive sensor/mux/load examples. Software teaching remains deferred.
- **2026-10-13 — Software teaching:** An offline [BaBot navigator](BaBot_導覽.html) was built from the unchanged `software/main.ino`. It embeds all 565 source lines, maps five verified architecture paths to code, and offers five theory modules with locally graded exercises. The builders and reviewed lesson data remain in `docs/`.

## Prototype bring-up — reported 2026-10-23

- **Base sensor-load repair:** The assembled Base originally had a 3296 marked `102` (1 kΩ) at RV1. The team removed it and soldered a fixed 10 kΩ resistor between RV1 pads 1 and 3; R18 measures 500 Ω. This is now a fixed sensor load, so there is no RV1 adjustment to perform in firmware or by turning a trimmer.
- **Base `cal 0` path check:** With Plate unplugged, J1 unpowered, Micro USB supplying logic, and a *second* 10 kΩ test resistor between U3-19 (`+5V_LOGIC`) and U3-1 (`PT00`), the initial ADC readings were erratic, sometimes near 1023. A loose external test-resistor contact was found; subsequent continuity and isolation checks showed about 10.5 kΩ from R18-1 to ground, ADC near zero without the fixture, and ADC 521 when the fixture fed R18-1 directly, bypassing the 4067. After reconnecting the fixture to PT00, `cal 0` remained stable at about **520/1023** versus the calculated **524/1023**, displaying about 9.84 kΩ at the RV1 pads. The Base PT00 → 4067 → A0/load path therefore passed this bench check. The exact cause of every transient high reading was not independently isolated; the test used only this one mux channel.
- **Plate receiver repair:** Q1 and Q9 initially did not trigger reliably on the assembled Plate. The team reports that replacing Q1 and Q9 resolved the issue. No quantitative before/after optical readings or failed-part analysis have been recorded yet.
- **Remaining Base work:** Servo actuation remains to be tested with an external regulated 5 V supply at J1, one unloaded servo at a time using [`test_code_base`](../software/test_code_base/README.md). The upstream balance code commands *positions* via `Servo.write(angle)`, so the existing position-control SG90 type is the appropriate starting point; a standard 360° continuous-rotation servo would control speed rather than hold a platform angle. Assess actual torque, fit, supply current, and mechanical travel before considering a position-control replacement. Full Base–Plate operation is not yet established by the PT00 fixture test.

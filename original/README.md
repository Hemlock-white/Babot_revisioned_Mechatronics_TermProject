# Original BaBot material

`upstream/BABOT-main/` is an unchanged local copy of [Johan Link's BABOT repository](https://github.com/JohanLink/BABOT), including its original `main.ino`, README, and [CC BY-NC 4.0 license](upstream/BABOT-main/LICENSE). Its original repository revision was not recorded in the downloaded folder, so this is identified as a local source snapshot rather than assigned an invented upstream commit.

`pcbway/` holds the original Base and Plate Gerbers, drill files, flying-probe data, and BOM downloads. `mechanical/` holds the downloaded combined STL; `schematics/` holds the downloaded schematic PDF. `web_captures/` contains saved pages and their support files for offline reference. These downloads have been kept separate from the redesigned electronics and the working software copy. The saved web pages and third-party page assets may have their own terms; their presence here does not change the upstream project's license.

Original project pages: [BaBot](https://ba-bot.com/), [build article](https://www.hackster.io/johanlinkemail/babot-build-your-own-ball-balancing-robot-2c1a5a), [GitHub source](https://github.com/JohanLink/BABOT).

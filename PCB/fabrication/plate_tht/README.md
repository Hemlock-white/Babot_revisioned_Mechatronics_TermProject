Paste layers are omitted because this is a through-hole board. The matching editable source is [`../../KiCad/BaBot_Plate_THT.kicad_pcb`](../../KiCad/BaBot_Plate_THT.kicad_pcb), with its `.kicad_pro`, unchanged schematic, and local `BaBot_THT.pretty` library in the same directory.

The owner's supplied routed board had 143 copper-only through-hole pads, which caused the earlier empty solder-mask exports. The integrated board and its 37 position-specific Plate IR/phototransistor footprints now include `*.Mask`, so a footprint refresh retains the correction. The original supplied project outside this repo was not overwritten. The rejected export and the old unrouted PCB are archived under [`../../../history/PCB/`](../../../history/PCB/).

KiCad 10 DRC after zone refill on the integrated project found **0 PCB violations and 0 unconnected items**; see [`DRC_report.json`](DRC_report.json). Each mask Gerber has **143 pad-opening flashes**. The plated drill file has **162 hits: 143 component pads and 19 vias**. The NPTH file is empty because the board has no NPTH pads. The Edge.Cuts outline is a single closed contour. Base U3 and Plate U1 have the same net on all 20 numbered pins.

The DRC report includes 205 schematic-parity warnings. All 143 pad-net warnings differ only by KiCad's schematic `/` prefix; all 62 footprint warnings differ only by the `BaBot_THT:` library prefix. Every name matches after removing that prefix. The unchanged schematic also reports 205 `endpoint_off_grid` ERC warnings inherited from its reconstruction. These do not show an open PCB connection, but deserve cleanup before schematic editing.

The job file specifies **two copper layers, 1.6 mm thickness, and a 100.0456 × 101.5921 mm outline**. This exceeds a 100 × 100 mm pricing tier. Confirm the fabricator's preview shows both mask openings and aligned drill holes. Physical component polarity, mechanical fit, and the straight-through pin-1 cable orientation still need to be checked on an assembled prototype.
